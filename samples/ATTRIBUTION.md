# Sample images: source and licence

The 20 images in this folder are **unmodified copies** from the MVTec AD dataset,
category `bottle`, test set. Only the file names were changed to
`<folder>_<original number>.png` (e.g. `broken_small_010.png` = `test/broken_small/010.png`).

All 20 come from **split B**, the held-out half that neither model was trained on,
so the demo shows the models on unseen bottles. Selection rule (no cherry-picking):
all 10 good images in split B, then the first 3 `broken_large`, first 3 `broken_small`
and first 4 `contamination` images of split B by file name.
